# Community Code of Conduct

TaskWitness is built around evidence, careful disagreement, and respect for uncertainty. The same
standards apply to its community.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique claims, code, and evidence—not people.
- State uncertainty and correct mistakes openly.
- Welcome newcomers and explain project conventions without gatekeeping.
- Protect private repositories, credentials, vulnerability details, and personal information.
- Keep discussions relevant to TaskWitness and its users.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate intimidation, doxxing,
spam, and publishing another person's private information are not tolerated. Neither is using a
security report, issue, or discussion to pressure maintainers into unsafe disclosure.

## Reporting and enforcement

For an ordinary moderation concern, flag the relevant GitHub content and include a brief factual
explanation. For a private report, use the repository's
[private advisory form](https://github.com/digsarab112/taskwitness/security/advisories/new) and
prefix the title with `Conduct:`. Do not include unrelated repository secrets.

Maintainers may edit or remove content, close or lock threads, limit participation, or ban an
account when necessary. Enforcement decisions should be proportionate, documented privately, and
focused on protecting the community.

This policy applies in the repository and in public spaces where someone officially represents
TaskWitness.
